# After the tide

A short first-person horror game set inside a coastal tide-observation station at 04:00, just before it closes for good. The sea has receded. The water inside is still rising.

Explore the station, record its sounds, and use relocated playback to draw a submerged presence away from your route. Recover the final tide-chart roll and complete the last handover.

Built with Three.js, WebGL 2 and Web Audio. All station geometry, textures, signs and sound effects are generated by the project. Desktop keyboard and mouse required. English and Simplified Chinese are available.

## Play

The repository includes a ready-to-run production build. From the project folder, start a local server with Python 3:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

Open **[the English version](http://127.0.0.1:8000/?lang=en)** in a desktop browser. Keep the terminal running while you play.

Choose **English** or **简体中文** at the top of the title or pause menu. Language changes preserve your current run and checkpoint. You can also open `?lang=zh-CN` directly. Without a URL override, the game uses your saved language preference; a first visit defaults to English.

`Play_After_The_Tide.html` is a portable, self-contained build with the same language selector. The HTTP build above is the normal browser-testing route.

## Controls

| Input | Action |
| --- | --- |
| WASD | Move |
| Mouse / arrow keys | Look around |
| Hold Shift | Sprint; loud footsteps and splashes attract attention |
| Caps Lock | Toggle quiet walking |
| E | Interact, collect an object or retrieve the placed recorder |
| Hold E | Operate a valve or breaker; locking detents retain progress when released |
| R | Record the previous six seconds of in-game sounds |
| Q | Place the recorder; playback starts after four seconds and lasts twenty seconds |
| Esc | Pause |

Read station documents with E and close them with E or Esc. Reading, losing window focus or releasing pointer lock pauses the game. The recorder uses game sound events, never your microphone.

Interaction prompts, blocked-action explanations, hold progress, warnings and immediate feedback share a lower-centre reading area. Important milestones save automatically in your browser. Continue from the same browser profile and address, including the port. Starting a new shift clears the previous checkpoint.

## Development

With Node.js 22.13+ (22.x) and npm:

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

Build the Vite production output with:

```sh
npm run build
```

A deterministic offline builder is also included. It uses the checked-in Three.js engine seed and generates both `dist/` and `Play_After_The_Tide.html` without fetching dependencies:

```sh
python3 scripts/build_dist.py
```

## Validation

The macOS offline verification runner uses the system JavaScriptCore executable:

```sh
python3 scripts/run_offline_checks.py
```

The validation record includes nine localization, mechanics, geometry and save suites, plus a production-bundle event route covering all 19 interaction targets. The route covers failure recovery, recorder retrieval, valves, power, paper collection, the ending and reset. Browser smoke checks cover bilingual menus, entrance signs and lower-centre feedback.

These offline tests use WebGL/DOM stubs. They do not establish a complete native-input browser playthrough or hardware GPU performance. See [known limits](KNOWN-LIMITS.md) and the [localization QA record](tests/LOCALIZATION-QA.md) for the exact scope. `?qa=1` enables read-only diagnostics; it does not provide a level skip.
